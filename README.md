# JobBot — вакансии дизайнера из Telegram с готовым откликом

Бот читает около 30 каналов с вакансиями (Грузия, РФ/СНГ, Европа и удалёнка), отбирает то, что подходит
продуктовому и UI/UX-дизайнеру, и присылает тебе карточку с готовым письмом. Под письмом кнопки:

- **✍️ Написать @рекрутер** — откроется чат с этим человеком, письмо уже вставлено. Остаётся нажать «Отправить».
- **✅ Отправил** — отметка для себя. Бот запоминает, кому ты писал, и предупредит, если попадётся тот же человек.
- **✏️ Изменить** — пришли свой текст (или `! короче и упомяни Figma`, если подключена нейросеть).
- **⏭ Пропустить**.

Сообщения отправляешь ты сам, поэтому риска бана за спам нет.

## Что нужно

Только **токен бота** от [@BotFather](https://t.me/BotFather): `/newbot` → имя → ник на `bot` → скопировать токен.
По желанию: `ANTHROPIC_API_KEY` с console.anthropic.com — тогда письмо пишется под каждую вакансию. Без ключа — шаблоны.

## Запуск на компьютере

1. **install.bat** — ставит библиотеки и открывает `.env` в Блокноте.
2. Вставь токен после `BOT_TOKEN=`, сохрани.
3. **start.bat**, затем открой своего бота в Telegram и нажми **/start** — бот запомнит тебя и начнёт присылать вакансии.

Работает, пока открыто окно start.bat.

## Бесплатно 24/7 через GitHub Actions

GitHub запускает бота каждые 5 минут (иногда с задержкой): он проверяет каналы, присылает новые карточки, обрабатывает
нажатые кнопки и выключается.

1. Создай **публичный** репозиторий на github.com (у приватных всего 2000 бесплатных минут в месяц — не хватит).
   Загрузи файлы из папки. `.env` и `data` **не загружай**. Файл `github_workflow_jobbot.yml` положи как
   `.github/workflows/jobbot.yml`.
2. **Settings → Secrets and variables → Actions → New repository secret**:
   - `BOT_TOKEN` — токен бота;
   - `OWNER_ID` — твой Telegram ID (бот пишет его в ответ на /start при запуске с компьютера, или узнай у @userinfobot);
   - `ANTHROPIC_API_KEY` — по желанию.
3. **Actions → jobbot → Run workflow**. Через минуту-две придут первые карточки.

Не запускай одновременно start.bat и GitHub — будут дубли. GitHub теоретически может отключить Actions в
репозитории, тогда просто запускай бота на компьютере.

## Команды

| Команда | Что делает |
|---|---|
| `/stats` | сколько найдено, отправлено, пропущено |
| `/scan` | проверить каналы сейчас (на компьютере) |
| `/pause`, `/resume` | пауза |
| `/channels` | список каналов; 🚫 — недоступен |
| `/add имя регион` | добавить канал (регион: `georgia`, `ru`, `eu_remote`) |
| `/remove имя` | убрать канал |
| `/pending` | прислать карточки, которые не дошли |

## Каналы

Бот читает публичные каналы через их веб-версию `t.me/s/имя`. Чаты (например, Tbilisi_IT) так не читаются — такой
канал бот сам пометит 🚫. Список каналов — в `config.yaml`, все проверены 23.09.2026.

## Как бот оценивает вакансию

`config.yaml`, раздел `keywords`: **stop** — сразу выкинуть (маникюр, WB, моушн, чужие резюме…); **must** — должно быть
«дизайнер / designer / UI / UX / Figma»; **plus/minus** — баллы. Проходит всё, что набрало **min_score** (3).
Много лишнего — подними до 4, мало — опусти до 2.

## Полный режим (если когда-нибудь заработает my.telegram.org)

Если заполнить в `.env` `TG_API_ID`, `TG_API_HASH` и запустить `login.bat` (он допишет `TG_SESSION`), бот будет сам
отправлять письмо и PDF по кнопке и читать ещё и чаты. Лимиты: 15 откликов в сутки, пауза 90 секунд.

## Если что-то не так

- **Бот молчит** — открой его в Telegram и нажми /start; на GitHub проверь секрет `OWNER_ID`.
- **Ссылка «Написать» открывает пустой чат** — письмо слишком длинное для ссылки; скопируй его из блока и вставь.
- **Проверки кода** — `python -m pytest tests`.
